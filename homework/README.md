## Структура папки задания

```
hwNN_<тема>/
├── README.md     # условие, вопросы формы, ваши ответы и результат
└── starter/      # официальный стартер с платформы (ноутбук / PDF), без изменений
```

Стартеры — чистые копии с сайта. Решайте в своих папках (`lessons/`, `projects/`), а стартер держите как эталон условия.

Мини-проект (командный) описан в [`materials/mini_project.md`](../materials/mini_project.md).
