# Фичи первой модели

Срезы: **2025-07-31** (train) и **2025-09-30** (OOT). Таргет — пользование (`data/targets/target_60d_usage.csv`: ≥ 3 approved и ≥ 800 тыс.). Все события режутся `<= snapshot`. `churn_customers_360` не используем.

Лаг один: последние 30 дней vs предыдущие 30. Плюс recency — дней с последней approved. Окна 7 и 60 не берём: неделя шум, «60 vs прошлые 60» почти уровень, не темп.

Сборка: `uv run python projects/customer_churn/scripts/build_features.py`  
Модель: `uv run python projects/customer_churn/scripts/train_first_model.py`

Файл: `data/model/features_60d.csv`.

## Зачем каждая группа

| Группа | Откуда | Зачем |
|--------|--------|-------|
| Recency | `days_since_last_txn` | Сколько дней молчит на t0 |
| Frequency / monetary 30д | `txn_cnt_30d`, `spend_30d` | Как часто и на сколько платил в последнем месяце |
| Лаг 30д | `txn_cnt_prev_30d`, `spend_prev_30d`, `txn_ratio_30d`, `spend_ratio_30d` | Тот же месяц до этого: остывает или нет |
| Доля отказов | declined за 30 дней | Трение, не ярлык ухода |
| Карты | `churn_cards` на дату среза | Сколько карт, есть ли блок |
| Приложение | `churn_app_events` | Ещё заходит, хотя картой реже платит |
| Продукты | открытые на t0 + события за 30д | Глубина отношений |
| Поддержка | тикеты, `fee_complaint` | Недовольство комиссией после тарифа |
| Подписка | активна / отменена, фейлы списаний | «Отвязываюсь» и «карта/денег нет» |
| Тариф | `effective_date ≤ snapshot` | Попал ли под повышение 1 июля |
| Кампании | контакт до t0 | Уже пытались удержать |
| Кто клиент | сегмент, стаж, регион, payroll, доход | Базовый профиль |

## Чего нет в X

Даты после snapshot, `returned_after_horizon`, готовый `is_churned` из 360, NPS (для июльского среза это будущее).

## Первая модель (не выдумка)

LightGBM, fit на июле, проверка на сентябре.

| | AUC | PR-AUC |
|--|----:|-------:|
| Июль, на train (запоминание) | 0.99 | 0.82 |
| Июль, 5-fold CV | **0.78** | 0.40 |
| Сентябрь OOT | **0.78** | 0.38 |

База в сентябре 5,8% — поэтому PR-AUC 0,38 это не «слабо», а сильно выше случайного (0,058). Цифру 0,99 на train не показываем как качество.

Топ по permutation на сентябре: активность за 30 дней, оборот и число операций за 60 дней, активность предыдущего окна. Gain на июле ещё любит регион — на OOT регион важность портит (переобучение).
