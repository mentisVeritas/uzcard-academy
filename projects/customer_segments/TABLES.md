# Таблицы `seg_*` — карта данных

Срез выгрузки: **2025-12-31**. Клиентов: **20 000**, тариф один — `standard`.

## Рабочие таблицы

| Таблица | Строк | Назначение |
|---------|------:|------------|
| `seg_customers` | 20 000 | Клиенты: демография, регион, дата регистрации |
| `seg_transactions` | ~12.1M | Операции 2024-01-01 — 2025-12-28: канал, категория, сумма |
| `seg_balances` | 427 598 | Средний остаток по месяцам |
| `seg_revenue_monthly` | 427 598 | Доход банка по месяцам (interchange, float, fees, ATM cost) |
| `seg_products` | 29 983 | Подключённые продукты и дата открытия |
| `seg_tariff_current` | 1 | Единый тариф на всех (15000 UZS/мес) |

## Забраковать

| Таблица | Вердикт | Почему |
|---------|---------|--------|
| `seg_transactions_archive` | Junk | Полный дубликат первых 6 мес. основной таблицы (2.7M txn_id совпадают 1:1) |
| `seg_customers_360` | Leakage | Готовая витрина: `crm_segment` A/B/C/D + `turnover_total` — чужой сегмент, выдавать за свой нельзя |
| `seg_rfm_old` | Leakage / junk | Старый RFM (recency/frequency/monetary) — готовая типология не нашей работы |
| `seg_temp` | Junk | Пустая служебная (0 строк) |

## Ключевые факты для решений

- Регистрация клиентов: **2019-01-01 — 2025-10-01** (медиана стажа ~3.6 года на 2025-12-31)
- Операции в данных только с **2024-01-01** — поведение до 2024 недоступно
- **245** клиентов без ни одной операции
- **4156** клиентов без подключённых продуктов
- Медиана паузы между операциями ~**0.4 дня** (активная база)
- `crm_segment` A/B/C/D — распределения оборота почти одинаковые → сегменты в 360 неинформативны
