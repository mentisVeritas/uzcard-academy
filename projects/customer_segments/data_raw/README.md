# Сырые таблицы seg_*

Разложите выгрузки после разведки:

```
data_raw/
├── useful/     # рабочие таблицы для признаков и сегментации
├── junk/       # старые копии, сэмплы, пустые служебные
└── leakage/    # готовые сегменты / чужие витрины (не выдавать за свой результат)
```

В каждой папке кратко зафиксируйте, почему таблица сюда попала.
