ndarray

ndarray: raqamli ma'lumotlarni saqlash turi

Matnni str, bitta sonni int saqlaydi. Sonlar to'plamini esa list da saqlaysiz. NumPy aynan ro'yxatni almashtiradi - raqamli ma'lumotlar uchun u samaraliroq va tezroq.

Python list: [1, 2, 3.0, 'ikki']

Moslashuvchan, lekin sekin

  • Har bir element - xotirada alohida Python obyekti
  • Elementlar turli manzillarda tarqoq joylashgan
  • Turlarni aralashtirish mumkin: int, str, float birga
  • Har qanday operatsiya Python siklini talab qiladi
NumPy ndarray: np.array([1, 2, 3, 4])

Qat'iy, lekin tez

  • Barcha elementlar - bir tur: float64, int32...
  • Xotirada bir uzluksiz blok
  • CPU ma'lumotlarni ketma-ket o'qiydi - sakrashsiz
  • Sikllarsiz operatsiyalar: a + b, a * 2, np.sum(a)

ndarray = N o'lchamli massiv. 1D - vektor, 2D - matritsa, 3D - kub (masalan, RGB-tasvir). Butun massiv uchun bitta ma'lumot turi.

Agar har bir element aynan 8 bayt (int64) egallasa, CPU istalgan elementning qayerda ekanligini oldindan biladi: manzil = bosh + indeks * 8.

Z-score - normaldan qanchalik uzoq

Z-score element o'rtachadan necha standart og'ishga farq qilishini ko'rsatadi.

z = (x - μ) / σ
x - qiymat
μ - o'rtacha
σ - std
|z| < 2
norma
2 ≤ |z| < 3
ehtiyot
|z| ≥ 3
anomaliya

Normal taqsimotda: ±1σ ichida 68%, ±2σ ichida 95%, ±3σ ichida 99.7%. z > 3 bo'lgan tranzaksiya - 370 ta holdan bittasi.

Normal taqsimot

Uch zona: norma - ehtiyot - anomaliya

z > 3 bo'lgan chiqish 0.3% dan kam hollarda uchraydi.

90 kunlik portfel volatilligi - 5 qatorda

Kunlik daromadliklarning standart og'ishi sqrt(252) ga ko'paytirilsa - yillik volatillik. Bu moliyaviy tahlilda standart formula.

np.random.seed(7) # 90 kunlik aksiya narxlarini simulyatsiya prices = np.cumprod(1 + np.random.randn(90) * 0.02) * 10_000 # Kunlik daromadlilik (%) returns = np.diff(prices) / prices[:-1] * 100 print(f"O'rtacha kunlik daromad: {returns.mean():.2f}%") print(f"Kunlik volatillik: {returns.std():.2f}%") print(f"Yillik volatillik: {returns.std() * np.sqrt(252):.1f}%") print(f"Maksimal tushish: {returns.min():.2f}%") print(f"Maksimal o'sish: {returns.max():.2f}%")

Simulyatsiya

Pi-ni 3 qatorda baholash - Monte-Karlo usuli

Kvadratga 1 000 000 ta tasodifiy nuqta tashlaymiz. Birlik doiraga tushganlarini hisoblaymiz. Ulush × 4 = Pi.

np.random.seed(0) N = 1_000_000 # [-1,1] x [-1,1] kvadratida tasodifiy nuqtalar x = np.random.uniform(-1, 1, N) y = np.random.uniform(-1, 1, N) # Nuqta birlik doiraga tushganmi? inside = (x**2 + y**2) <= 1.0 pi_estimate = 4.0 * inside.sum() / N print(f"Pi bahosi: {pi_estimate:.5f}") print(f"Haqiqiy Pi: {np.pi:.5f}") print(f"Xato: {abs(pi_estimate - np.pi):.5f}")
Pi bahosi: 3.14136 Haqiqiy Pi: 3.14159 Xato: 0.00023

Bu o'yinchoq emas - moliyaviy kompaniyalar Monte-Karlo-ni portfel riskini baholash uchun ishlatadi. NumPy 1 000 000 ta amalni millisekundlarda bajaradi.
