Типы соединений

Четыре типа merge

ТипСтроки в результатеСтроки без парыПрименение
innerТолько строки с совпадением в обеих таблицахОтбрасываются без предупрежденияНужна только полная информация

На практике используются inner и left. inner молча удаляет строки без пары; left молча создаёт NaN. Оба требуют проверки результата.

Edge case 3

Несовпадение типов ключа: 0 строк без ошибки

Проблема

int64 vs object (str)

Ключ в одной таблице int64, в другой object. Pandas не приводит типы автоматически: merge возвращает пустой DataFrame.

Решение

Привести типы явно

Проверить df.dtypes для обеих таблиц. Привести ключевой столбец к единому типу через astype.

# Пример: orders.product_id = int64, products.product_id = object print(orders["product_id"].dtype) # int64 print(products["product_id"].dtype) # object bad = pd.merge(orders, products, on="product_id") print(len(bad)) # 0, ошибки нет products["product_id"] = products["product_id"].astype(int) good = pd.merge(orders, products, on="product_id") print(len(good)) # 820

0 строк после merge без исключения: почти всегда dtype mismatch или опечатка в имени ключа.

Вертикальная склейка

pd.concat: объединение таблиц одинаковой структуры

merge объединяет таблицы по ключу. concat склеивает таблицы с одинаковым набором столбцов по строкам.

jan = pd.read_csv("orders_jan.csv") feb = pd.read_csv("orders_feb.csv") mar = pd.read_csv("orders_mar.csv") all_data = pd.concat( [jan, feb, mar], ignore_index=True ) print(all_data.shape)
ПараметрНазначение
ignore_index=TrueСброс индексов; без него дублируются
axis=1Склейка по столбцам
keys=["jan","feb"]Метка источника в MultiIndex

Без ignore_index=True: df.loc[0] вернёт несколько строк, по одной из каждого файла.

groupby: синтаксис

Одна функция, несколько метрик, топ-N

# одна агрегация df.groupby("city")["revenue"].sum() # несколько метрик df.groupby("city")["revenue"].agg(["sum", "mean", "count"]) # именованные агрегации (pandas >= 0.25) df.groupby("city").agg( total =("revenue", "sum"), avg =("revenue", "mean"), orders =("order_id", "count") ) # топ-5 df.groupby("city")["revenue"].sum()\ .sort_values(ascending=False).head(5) # reset_index() -> обычный DataFrame df.groupby("city")["revenue"].sum().reset_index()

groupby: два ключа

Группировка по двум столбцам и матрица значений

# группировка по двум столбцам -> MultiIndex matrix = df.groupby(["city", "category"])["revenue"].sum() # unstack: второй уровень индекса -> столбцы pivot = matrix.unstack(level="category").fillna(0) # pivot_table: то же самое, короче pd.pivot_table(df, values="revenue", index="city", columns="category", aggfunc="sum", fill_value=0 )

unstack работает с результатом groupby. pivot_table принимает DataFrame напрямую. Результат идентичен.

Edge case: groupby

NaN в столбце группировки: группа исчезает по умолчанию

# NaN в city после left join df["city"].isna().sum() # 15 # По умолчанию NaN-группа исчезает r1 = df.groupby("city")["revenue"].sum() print(len(r1)) # 8 городов # dropna=False: NaN как отдельная группа r2 = df.groupby("city", dropna=False)["revenue"].sum() print(len(r2)) # 9 групп # альтернатива: заполнить NaN до groupby df["city"] = df["city"].fillna("Noma'lum")
