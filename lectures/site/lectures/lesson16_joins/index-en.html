Join types

Four types of merge

TypeRows in resultUnmatched rowsUse case
innerOnly rows that match in both tablesDropped without warningOnly complete records are needed
leftAll left rows + matches from the rightNaN in right-table columnsKeep every row of the main table
rightAll right rows + matches from the leftNaN in left-table columnsRare; replace with left and swapped tables
outerAll rows from both tablesNaN on both sidesFull mismatch diagnostics

In practice inner and left are used. inner silently drops unmatched rows; left silently creates NaN. Both require checking the result.

Syntax

pd.merge: main parameters

# basic form result = pd.merge(left, right, on="key", how="inner") # keys with different names in two tables pd.merge(orders, customers, left_on="cust_id", right_on="customer_id", how="left") # composite key pd.merge(left, right, on=["region", "date"]) # column name conflict -> suffixes pd.merge(left, right, on="id", suffixes=("_order", "_product")) # mandatory check after merge print("Before:", len(left), "After:", len(result)) result.isna().sum()

Edge case 3

Key dtype mismatch: 0 rows, no error

Problem

int64 vs object (str)

The key is int64 in one table and object in the other. Pandas does not cast types automatically: merge returns an empty DataFrame.

Fix

Cast the types explicitly

Check df.dtypes for both tables. Cast the key column to a single type with astype.

# Example: orders.product_id = int64, products.product_id = object print(orders["product_id"].dtype) # int64 print(products["product_id"].dtype) # object bad = pd.merge(orders, products, on="product_id") print(len(bad)) # 0, no error products["product_id"] = products["product_id"].astype(int) good = pd.merge(orders, products, on="product_id") print(len(good)) # 820

0 rows after merge with no exception: almost always a dtype mismatch or a typo in the key name.

pd.concat: combining tables with the same structure

merge joins tables on a key. concat stacks tables with the same columns row-wise.

jan = pd.read_csv("orders_jan.csv") feb = pd.read_csv("orders_feb.csv") mar = pd.read_csv("orders_mar.csv") all_data = pd.concat( [jan, feb, mar], ignore_index=True ) print(all_data.shape)
ParameterPurpose
ignore_index=TrueReset indices; without it they duplicate
axis=1Concatenate column-wise
keys=["jan","feb"]Source label in a MultiIndex

Without ignore_index=True: df.loc[0] returns several rows, one per file.

groupby: syntax

One function, several metrics, top-N

# single aggregation df.groupby("city")["revenue"].sum() # several metrics df.groupby("city")["revenue"].agg(["sum", "mean", "count"]) # named aggregations (pandas >= 0.25) df.groupby("city").agg( total =("revenue", "sum"), avg =("revenue", "mean"), orders =("order_id", "count") ) # top-5 df.groupby("city")["revenue"].sum()\ .sort_values(ascending=False).head(5) # reset_index() -> a plain DataFrame df.groupby("city")["revenue"].sum().reset_index()

groupby: two keys

Grouping by two columns and a value matrix

# grouping by two columns -> MultiIndex matrix = df.groupby(["city", "category"])["revenue"].sum() # unstack: second index level -> columns pivot = matrix.unstack(level="category").fillna(0) # pivot_table: the same, shorter pd.pivot_table(df, values="revenue", index="city", columns="category", aggfunc="sum", fill_value=0 )

unstack works on a groupby result. pivot_table takes a DataFrame directly. The result is identical.

Edge case: groupby

NaN in the grouping column: the group disappears by default

# NaN in city after a left join df["city"].isna().sum() # 15 # By default the NaN group disappears r1 = df.groupby("city")["revenue"].sum() print(len(r1)) # 8 cities # dropna=False: NaN as a separate group r2 = df.groupby("city", dropna=False)["revenue"].sum() print(len(r2)) # 9 groups # alternative: fill NaN before groupby df["city"] = df["city"].fillna("Noma'lum")

Full pipeline

Load → clean → merge → groupby

# 1. load orders = pd.read_csv("orders.csv") customers = pd.read_csv("customers.csv") products = pd.read_csv("products.csv") # 2. clean products["price_uzs"] = pd.to_numeric( products["price_uzs"].astype(str).str.replace(r"[^\d]", "", regex=True), errors="coerce") customers["city"] = customers["city"].str.strip().str.title() # 3. check key uniqueness assert customers["customer_id"].nunique() == len(customers) assert products["product_id"].nunique() == len(products) # 4. assemble df = pd.merge(orders, customers, on="customer_id", how="left") df = pd.merge(df, products, on="product_id", how="left") df["revenue"] = df["price_uzs"] * df["quantity"] # 5. analytics df.groupby("city")["revenue"].sum().sort_values(ascending=False)
