Muammo

int64 vs object (str)

Bir jadvalda kalit int64, boshqasida object. Pandas turlarni avtomatik keltirmaydi: merge boʻsh DataFrame qaytaradi.

groupby: sintaksis

Bitta funksiya, bir nechta metrika, top-N

# bitta agregatsiya df.groupby("city")["revenue"].sum() # bir nechta metrika df.groupby("city")["revenue"].agg(["sum", "mean", "count"]) # nomlangan agregatsiyalar (pandas >= 0.25) df.groupby("city").agg( total =("revenue", "sum"), avg =("revenue", "mean"), orders =("order_id", "count") ) # top-5 df.groupby("city")["revenue"].sum()\ .sort_values(ascending=False).head(5) # reset_index() -> oddiy DataFrame df.groupby("city")["revenue"].sum().reset_index()

groupby: ikki kalit

Ikki ustun boʻyicha guruhlash va qiymatlar matritsasi

# ikki ustun boʻyicha guruhlash -> MultiIndex matrix = df.groupby(["city", "category"])["revenue"].sum() # unstack: indeksning ikkinchi darajasi -> ustunlar pivot = matrix.unstack(level="category").fillna(0) # pivot_table: xuddi shu, qisqaroq pd.pivot_table(df, values="revenue", index="city", columns="category", aggfunc="sum", fill_value=0 )

unstack groupby natijasi bilan ishlaydi. pivot_table DataFrame-ni toʻgʻridan-toʻgʻri oladi. Natija bir xil.

Toʻliq pipeline

Yuklash → tozalash → merge → groupby

# 1. yuklash orders = pd.read_csv("orders.csv") customers = pd.read_csv("customers.csv") products = pd.read_csv("products.csv") # 2. tozalash products["price_uzs"] = pd.to_numeric( products["price_uzs"].astype(str).str.replace(r"[^\d]", "", regex=True), errors="coerce") customers["city"] = customers["city"].str.strip().str.title() # 3. kalitlar yagonaligini tekshirish assert customers["customer_id"].nunique() == len(customers) assert products["product_id"].nunique() == len(products) # 4. yigʻish df = pd.merge(orders, customers, on="customer_id", how="left") df = pd.merge(df, products, on="product_id", how="left") df["revenue"] = df["price_uzs"] * df["quantity"] # 5. tahlil df.groupby("city")["revenue"].sum().sort_values(ascending=False)
