    Problem 1

    Column names have spaces and units of measure

    list(df.columns) reveals the real names. A column with a space in its name cannot be accessed via dot notation; units of measure clutter code.

    # df.columns before cleaning [' DateTime', 'Card ID', 'Merchant ', 'Category', 'Region', 'Amount (UZS)', 'Status', 'Is Online', 'Cashback (UZS)', 'MCC']

    The leading space in ' DateTime' is part of the column name. Dot access fails: df. DateTime throws an error. Normalize before any other work.

    Problem 2

    amount column stores strings instead of numbers

    df.info() reports object dtype for Amount. Three causes: space separator, comma separator, and a text value where the amount is missing.

    # df["Amount (UZS)"].head(8) 0 '154 700' # thousands separator: space 1 '181,000' # thousands separator: comma 2 '2300000' # no separator 3 'н/д' # amount not recorded 4 '45 900' Name: Amount (UZS), dtype: object

    Problems 3-4-5

    Duplicates, region spelling variants, nulls

    Duplicates

    df.duplicated().sum() returned 120. One transaction exported twice.

    120 duplicate rows

    Region: 33 variants instead of 8

    value_counts() showed 'Tashkent', ' Tashkent', 'tashkent', 'TASHKENT' — different case and spaces split one value.

    33 unique variants

    Nulls

    isna().sum(): many NaN in cashback (no loyalty program), a few hundred in region (data never arrived).

    cashback: ~4 000 NaN

    Nulls in cashback and region mean different things. cashback = 0 (no cashback). region = 'Unknown' (data missing). Handle them separately.

    Stage 4

    Data cleaning tools

    .str methods

    strip, lower, title, replace. Remove spaces, normalize case, strip characters. Applied to string Series via .str.

    pd.to_numeric(errors="coerce")

    Converts text to number. Anything that can't be converted becomes NaN. Won't raise on 'н/д'.

    drop_duplicates / dropna / fillna

    drop_duplicates removes repeated rows. dropna drops rows with NaN. fillna(x) fills NaN with value x.

    astype("category")

    Converts repeated text to a compact numeric type. Saves memory. Unique values stored once.

    Cleaning

    Eight steps from raw file to clean table

    #StepCommandWhat it does
    1Column namesstr.strip().str.lower().str.replace()Removes spaces and units
    2Duplicatesdrop_duplicates()Removes 120 duplicate rows
    3Amount to numberstr.replace() + to_numeric(errors="coerce")Strips spaces/commas, 'н/д' becomes NaN
    4Datepd.to_datetime()Converts string to datetime dtype
    5Regionstr.strip().str.title().fillna("Unknown")33 variants down to 8 cities
    6Online flagmap({"Y": True, "N": False})Y/N text to boolean
    7Cashbackfillna(0)NaN becomes 0 (no cashback)
    8Categoriesastype("category")Text columns to compact type

    Question

    Why can't we write df["amount"] = df["amount"].astype(float)?

    The column has '154 700' and 'н/д' strings. What happens if we try a direct conversion?

    Answer

    astype(float) raises ValueError: it doesn't know what to do with 'н/д' and spaces

    to_numeric(errors="coerce") doesn't raise: values that can't convert become NaN. The space in '154 700' must be removed first with str.replace, otherwise it also becomes NaN.

    # Wrong — raises ValueError df["amount"] = df["amount"].astype(float) # Correct — clean first, then convert df["amount"] = pd.to_numeric( df["amount"].astype(str).str.replace(r"[ ,]", "", regex=True), errors="coerce")
