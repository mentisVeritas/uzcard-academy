    Проблема 1

    Пробелы и единицы измерения в именах столбцов

    Команда list(df.columns) показывает реальные имена. К столбцу с пробелом в имени нельзя обратиться через точку, а единицы измерения засоряют код.

    # df.columns до чистки [' DateTime', 'Card ID', 'Merchant ', 'Category', 'Region', 'Amount (UZS)', 'Status', 'Is Online', 'Cashback (UZS)', 'MCC']

    Пробел в начале ' DateTime' является частью имени столбца. Обратиться к нему через точку невозможно: df. DateTime вызовет ошибку. Необходима нормализация перед началом работы.

    Проблема 2

    Столбец amount хранит строки вместо чисел

    df.info() показывает тип object для столбца Amount. Три причины: пробел как разделитель, запятая как разделитель и текстовое значение там, где суммы нет.

    # df["Amount (UZS)"].head(8) 0 '154 700' # пробел как разделитель тысяч 1 '181,000' # запятая как разделитель 2 '2300000' # без разделителя 3 'н/д' # сумма не записана 4 '45 900' Name: Amount (UZS), dtype: object

    Этап 4

    Инструменты чистки данных

    .str методы

    strip, lower, title, replace. Убирают пробелы, приводят регистр, удаляют символы. Применяются к Series строк через .str.

    pd.to_numeric(errors="coerce")

    Переводит текст в число. Всё, что не конвертируется - становится NaN. Не падает с ошибкой на 'н/д'.

    drop_duplicates / dropna / fillna

    drop_duplicates удаляет повторы. dropna удаляет строки с NaN. fillna(x) заполняет NaN значением x.

    astype("category")

    Переводит повторяющийся текст в компактный числовой тип. Экономит память. Уникальные значения хранятся один раз.

    Вопрос

    Почему нельзя просто написать df["amount"] = df["amount"].astype(float)?

    Столбец содержит строки '154 700' и 'н/д'. Что произойдёт, если попробовать прямой перевод?

    Ответ

    astype(float) вызовет ValueError: не знает, что делать с 'н/д' и пробелами

    to_numeric(errors="coerce") не вызывает исключение: значения, которые не удалось преобразовать, получают NaN. Пробел внутри числа необходимо удалить заранее через str.replace, иначе '154 700' также станет NaN.

    # Неправильно - упадёт с ValueError df["amount"] = df["amount"].astype(float) # Правильно - сначала чистим, потом конвертируем df["amount"] = pd.to_numeric( df["amount"].astype(str).str.replace(r"[ ,]", "", regex=True), errors="coerce")
