Объединение

merge соединяет две таблицы по ключу

Данные разнесены по таблицам: в транзакциях есть card_id, но нет сегмента клиента. merge подтягивает столбцы из второй таблицы по общему ключу. Это аналог JOIN из SQL, который будет в Лекции 15.

Виды join

inner, left, right, outer

Ключ может встречаться не во всех таблицах. Тип join решает, какие строки попадут в результат.

inner

Только общие ключи, есть в обеих таблицах.

left

Все строки левой таблицы, нет пары -> NaN.

right

Все строки правой таблицы.

outer

Все ключи обеих таблиц.

Чаще всего нужен left: сохранить все свои данные и подтянуть справочное, ничего не потеряв.

Вопрос

После left merge таблица выросла с 10 000 до 12 000 строк. Как такое возможно при left join?

Left join должен сохранять все строки левой таблицы и не добавлять новые. Но строк стало больше.

Ответ

Many-to-many: один card_id встретился в правой таблице несколько раз

merge дублирует строку транзакции для каждой пары. Если один card_id в cards повторяется - каждая транзакция с этим id размножается. Решение: cards.drop_duplicates("card_id") перед merge.

Вопрос

В столбце region у 300 строк стоит NaN. Сколько из них войдёт в groupby("region").sum()?

Данные реальные: часть транзакций пришла без региона. groupby вызывается без дополнительных параметров.

Ответ

Ни одна: groupby молча выбрасывает NaN-ключи

По умолчанию groupby отбрасывает строки, где ключевой столбец NaN (dropna=True). 300 транзакций без региона не войдут ни в одну группу. Чтобы получить группу NaN: df.groupby("region", dropna=False).sum().

Сводные таблицы

pivot_table: агрегат по двум измерениям

groupby сворачивает по одному ключу. pivot_table раскладывает агрегат по двум: одно измерение в строки, другое в столбцы. Например, оборот по регионам (строки) и категориям (столбцы) в одной таблице.

Время

Дата это отдельный тип данных

to_datetime превращает строку в дату. После этого аксессор .dt даёт час, день, месяц, а resample группирует строки по интервалам времени (по часам, по дням) и считает агрегат внутри каждого. Подробнее о временных рядах в следующих лекциях.
